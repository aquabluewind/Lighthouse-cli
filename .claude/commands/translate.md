知識レベルの低い人でもAIへの質問を上手くできるよう、入力を分析して3ステップで変換・回答するシステムを起動します。

引数がある場合はその質問を直接処理します。引数がない場合は対話モードで起動します。

**使い方:**
- `/translate` — 対話モード（何度でも質問できる）
- `/translate AIってどうやって動くの？` — 一発質問モード

**処理の流れ:**
1. 知識レベル（1〜5）を自動判定し、質問の意図を読み取る
2. プロ向けの精密なプロンプトに変換してClaudeで回答取得
3. 入力者のレベルに合わせた分かりやすい言葉で説明

以下のコマンドを実行してください:

```bash
cd /home/user/Lighthouse-cli && npm run translate -- $ARGUMENTS
```
