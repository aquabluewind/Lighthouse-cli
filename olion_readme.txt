  OLION  オリオン  -  ORION SHOOTER
  NEC PC-6001 N60-BASIC ゲーム
======================================

【ゲーム概要】
あなたはオリオン号のパイロット！
宇宙から押し寄せる敵（W）をたおしてハイスコアをめざせ！

【操作方法】
  Z    : 左に移動
  X    : 右に移動
  SPC  : ビームはっしゃ

【ルール】
 ・敵(W)をビームでうつと10点×レベル
 ・敵(W)がプレイヤー(A)にぶつかるとライフ-1
 ・ライフが0になるとゲームオーバー
 ・スコアがたまるとレベルアップ（LV200点ごと）

【キャラクター】
  A   ： プレイヤー（オリオン号）
  W   ： てき（エイリアン）
  |   ： ビーム（たま）
  *   ： 命中エフェクト

【入力方法】
  1. NEC PC-6001でN60-BASICを起動
  2. NEW[RETURN]でプログラムをクリア
  3. 以下のコマンドでリストを入力:
       LOAD "CAS:"  (テープから読み込む場合)
     または olion.bas の内容を直接キー入力
  4. RUN[RETURN] でゲームスタート

【動作環境】
  機種  : NEC PC-6001 / PC-6001mkII
  BASIC : N60-BASIC (標準搭載)
  メモリ: 8KB以上
